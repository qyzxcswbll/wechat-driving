# 驾校预约小程序 — 设计规格

> 最后更新：2026-06-18

## 1. 项目概述

为教练开发的微信小程序，供学车学员预约参观驾校和预约上课时间，同时为教练提供学员咨询管理和预约审核功能。

**目标用户：** 教练（管理员） + 学车学员
**技术选型：** 微信原生小程序 + 微信云开发（云数据库 + 云函数 + 云存储）
**设计原则：** 简约、易用、一个人即可维护

---

## 2. 页面结构

## 4. 核心业务流程

### 4.1 参观咨询流程

```
学员填写表单(姓名+先生/女士+手机号+备注)
  → 保存联系方式到学员档案（下次自动填充）
  → 写入 visits（status: pending）
  → 微信订阅消息通知教练
  → 教练在"咨询学员"列表查看
  → 教练通过微信/电话联系学员
  → 标记为 contacted
```

### 4.2 上课预约流程

```
学员填写信息(姓名+先生/女士+手机号+科目+挡位)
  → 添加多个日期（日期显示星期几+时间系统选择器）
  → 保存联系方式到学员档案
  → 批量写入 bookings（每条 status: pending）
  → 微信订阅消息通知教练
  → 教练在"预约管理"查看（显示同时段已有X人预约）
  → 教练点击接受 → status → accepted（加入课程表）
  → 教练点击拒绝 → 输入原因 → status → rejected
  → 微信订阅消息通知学员结果
```

### 4.3 学员取消预约

```
学员在"我的预约"点取消
  → 弹窗确认
  → status → cancelled
  → 微信订阅消息通知教练
```

### 4.4 同时段预约限制

- 同一天 ±1小时内的预约视为同一时段
- 管理端预约卡片提示「👥 当前时段已有 X 人预约」
- 教练根据情况决定接受/拒绝（上限4人由教练把控）

## 5. 通知机制

统一使用一个模板：**订阅项目进展更新提醒**

| 触发时机 | 通知对象 | 模板内容 |
|---------|---------|---------|
| 学员提交参观/预约 | 教练 | 订阅项目+项目进展(待处理/待回复)+更新时间 |
| 教练接受/拒绝预约 | 学员 | 订阅项目+项目进展(已接受/已拒绝)+更新时间 |
| 学员取消预约 | 教练 | 订阅项目(学员取消预约)+项目进展(已取消)+更新时间 |

授权方式：
- 学员：提交预约/参观时自动弹窗请求授权
- 教练：管理首页底部「如未收到通知，点此重新授权」
- 授权一次可发一条，再次操作会再次弹窗

## 7. 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 开发框架 | 原生微信小程序 | 云开发支持最好，体积最小 |
| 后端 | 微信云开发 | 零运维、免费额度够用 |
| 身份识别 | OpenID 自动识别 | 无需额外登录流程 |
| 管理员配置 | ⚙️ 设置页密码操作 | 避免手动插数据库 |
| 预约模式 | 学员自由提交+教练审核 | 灵活，适合单人排班 |
| 一次性多天预约 | 表单动态添加日期行 | 方便学员批量操作 |
| 学员取消 | 待确认状态可取消 | 减少教练管理负担 |
| 联系方式保存 | 提交时自动存入学员档案 | 填过一次永久生效 |
| 时间选择器 | 系统 picker (方案D) | 稳定、任意时间可选、显示星期几 |
| 课程表 | 61天滑动+姓名标签+详情弹窗 | 可浏览过去/未来、多学员同时间可见 |
| 通知 | 统一一个订阅模板 | 简化配置，教练/学员通用 |
| 客服反馈 | `<button open-type="contact">` | 微信原生，无需额外开发 |
