# 平安驾校微信小程序 · 上线部署操作手册

本文档指导你从"跑通代码"到"正式上线"的全流程操作。请按顺序一步步完成。

---

## 开发与部署流程说明

> **开发阶段：** 你用你自己的微信进行开发和调试，此时你是"学员"身份
>
> **上线阶段：** 在 `admins` 数据库中插入教练的信息后，教练打开小程序就自动变成"管理员"
>
> **不需要改代码，逻辑已经写好：** `login` 云函数自动判断——查 `admins` 有记录就是管理员，没有就是学员

## 1. 准备工作

### 1.1 安装微信开发者工具

下载并安装 **微信开发者工具**（稳定版）：
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

> 你只需要它的上传和预览功能，日常改代码还是在 VS Code 中进行。

### 1.2 注册小程序并获取 AppID

1. 打开 https://mp.weixin.qq.com/
2. 点击「立即注册」→ 选择「小程序」
   - 用**你本人的邮箱**注册（未注册过微信公众平台的）
   - 主体类型选「个人」
   - 用你本人的身份证信息完成实名
3. 注册完成后，在「开发」→「开发管理」→「开发设置」中复制 **AppID（小程序ID）**

> 小程序是**以你的名义注册**用于发布和运营，教练不需要注册账号。

## 2. 创建微信云开发环境

1. 用微信开发者工具打开本项目
   - 打开工具 → 项目 → 导入项目
   - 目录选择：`d:/Code/wechat-driving`
   - AppID：填入上一步获取的 AppID
   - 点击导入

2. 开通云开发
   - 点击顶部工具栏的「云开发」按钮（云朵图标 ☁️）
   - 点击「开通」
   - 环境名称：填 `driving-school-prod`
   - 点击确定，等待创建完成（约 1-2 分钟）

3. 记录环境 ID
   - 创建完成后，云开发控制台顶部显示 `环境 ID：driving-school-prod-xxxxx`
   - **复制这个环境 ID**，下一步要用

---

## 3. 创建数据库集合

1. 在云开发控制台中，点击「数据库」标签页
2. 点击「创建集合」，依次创建以下 **4 个集合**：

| 集合名 | 说明 |
|--------|------|
| `students` | 学员信息 |
| `admins` | 管理员（教练） |
| `visits` | 参观咨询记录 |
| `bookings` | 上课预约记录 |

3. 为 `students` 集合的 `openid` 字段创建**唯一索引**
   - 点击 `students` 集合 →「索引管理」→「添加索引」
   - 字段名：`openid`，方向：**唯一**

4. 为 `bookings` 集合创建普通索引

| 字段名 | 方向 |
|--------|------|
| `openid` | 升序 |
| `status` | 升序 |
| `date` | 升序 |

## 4. 配置项目参数

### 4.1 配置云环境 ID

打开 `miniprogram/env.js`：

```javascript
const CLOUD_ENV = 'driving-school-prod-xxxxx'   // ← 替换为第2步获取的环境ID
const ADMIN_OPENID = ''                          // 先留空，上线前再填
```

### 4.2 配置 AppID

打开 `project.config.json`，修改第 12 行：

```json
"appid": "wx你的AppID"  // ← 替换为第1.2步获取的AppID
```

## 5. 上传云函数

共 11 个云函数需要上传到云端：

```
cloudfunctions/
├── login/          ├── submitBooking/
├── getSchoolInfo/  ├── getMyBookings/
├── submitVisit/    ├── getAllBookings/
├── getVisits/      ├── handleBooking/
├── markContacted/  ├── getSchedule/
└── sendNotify/
```

### 操作步骤

1. 在微信开发者工具中，展开左侧 `cloudfunctions/` 目录
2. 右键点击每个文件夹 →「上传并部署：云端安装依赖」
3. 依次上传 **全部 11 个云函数**（第一次较慢，每个约 30 秒）

## 6. 真机调试（你作为学员）

### 6.1 预览小程序

1. 点击开发者工具顶部的「预览」按钮
2. 用**你自己的微信**扫码打开小程序
3. 此时 `admins` 集合还没数据，你的身份是 **学员**

### 6.2 测试学员流程

- [ ] 打开小程序 → 自动跳转学员首页
- [ ] 首页显示驾校信息（名称/地址/教练/简介）—— 因为 `admins` 还没数据，可能空白，正常
- [ ] 点击「预约参观」→ 填写手机号 → 提交
- [ ] 点击「预约学车」→ 选择日期时间科目 → 添加多个日期 → 提交
- [ ] 点击底部「我的」→ 看到刚才提交的预约记录
- [ ] 查看预约详情
- [ ] 点击底部「联系」→ 显示页面（二维码先为空）

> 此时 `admins` 集合为空，驾校信息暂时不显示、管理端进不去——这是预期的。

## 7. 配置教练为管理员

这一步是关键——把教练的信息录入数据库，他打开小程序时就会自动识别为管理员。

### 7.1 获取教练的微信 OpenID

需要先让教练扫码登录一次小程序，系统会自动记录他的 OpenID。

**方法一（直接）：** 让教练用微信扫码你预览的小程序 → 他会自动注册为学员 → 在云开发控制台 `students` 集合中可以看到一条新记录 → 复制里面的 `openid` 字段值

**方法二（提前准备）：** 你也可以在微信公众平台 →「开发」→「开发管理」→「开发设置」中查看小程序的 OpenID 对照表，但需要小程序已发布上线才能查到。

### 7.2 插入管理员记录

1. 云开发控制台 → 数据库 → `admins` 集合
2. 点击「添加记录」→ 选择「插入一条记录」
3. 把下面的 JSON 粘贴进去，**修改其中的值**：

```json
{
  "openid": "上一步获取的教练OpenID",
  "name": "张教练",
  "phone": "教练的手机号",
  "schoolName": "平安驾校",
  "address": "驾校地址，如：广东省汕头市龙湖区xx路xx号",
  "intro": "专业驾驶教练，多年教学经验，耐心负责，C1/C2均可教学。",
  "wechatQR": ""
}
```

4. 点击「确定」保存

### 7.3 可选：配置 env.js 中的 ADMIN_OPENID

`env.js` 中的 `ADMIN_OPENID` 目前未使用（作为备用），你也可以填上教练的 OpenID。

## 8. 教练端真机调试

### 8.1 让教练扫码测试

1. 用**教练的微信**扫码预览小程序
2. 因为 `admins` 集合已有他的记录 → 自动跳转**管理首页**

### 8.2 测试管理员流程

- [ ] 首页显示统计数据（待处理数/咨询数/已确认数）
- [ ] 点击「预约管理」→ 看到学员（你）之前提交的预约
- [ ] 点击「接受」→ 预约变为已接受
- [ ] 点击「拒绝」→ 弹窗输入原因 → 变为已拒绝
- [ ] 点击「咨询学员」→ 看到参观咨询列表
- [ ] 点击「课程表」→ 按周查看已确认的课程
- [ ] 底部导航 4 个 Tab 均可正常切换

### 8.3 重新用你的微信扫码验证

用你自己的微信再扫码，确认：
- [ ] 学员流程仍然正常
- [ ] 你之前提交的预约状态已更新（如被接受/拒绝）

## 9. 上传微信二维码到云存储

### 9.1 准备二维码

1. 让教练打开微信 → 我 → 点头像 → 点「二维码名片」
2. 截图或拍照发给你
3. 图片命名为 `wechat-qr.jpg`

### 9.2 上传到云存储

1. 云开发控制台 →「存储」标签页
2. 点击「上传文件」，选择 `wechat-qr.jpg`
3. 上传成功后，点击文件右侧的「复制文件 ID」
4. 回到数据库 → `admins` 集合 → 打开教练那条记录
5. 把 `wechatQR` 字段改为刚复制的文件 ID（格式：`cloud://driving-school-prod-xxxx.xxx/wechat-qr.jpg`）
6. 点击「确定」保存

## 10. 配置订阅消息模板

### 10.1 申请模板

1. 打开微信公众平台（https://mp.weixin.qq.com/）
2. 登录小程序账号
3. 左侧菜单：「功能」→「订阅消息」
4. 点击「公共模板库」
5. 搜索以下模板并选用：

| 用途 | 推荐搜索关键词 | 模板内容建议 |
|------|---------------|-------------|
| 新预约通知 → 教练 | "预约提醒"、"新订单通知" | 学员姓名、预约日期、预约时间、提交时间 |
| 预约结果 → 学员 | "状态通知"、"审核结果通知" | 预约日期、预约时间、审核状态、备注 |

6. 选用后，记录每个模板的 **模板 ID**

### 10.2 在代码中配置模板 ID

**文件 1：** `miniprogram/pages/student/visit/index.js`
```javascript
wx.requestSubscribeMessage({
  tmplIds: ['TEMPLATE_ID_VISIT_NOTIFY'],  // ← 替换为实际模板ID
  complete: () => { ... }
})
```

**文件 2：** `miniprogram/pages/student/booking/index.js`
```javascript
wx.requestSubscribeMessage({
  tmplIds: ['TEMPLATE_ID_BOOKING_NOTIFY'],  // ← 替换为实际模板ID
  complete: () => { ... }
})
```

**文件 3：** `miniprogram/pages/admin/bookings/index.js`
找到 `acceptBooking` 和 `rejectBooking` 中的 `// TODO` 注释，替换为实际的 `cloud.sendNotify()` 调用：

```javascript
const booking = this.data.list.find(b => b._id === e.currentTarget.dataset.id)
cloud.sendNotify({
  openid: booking.openid,
  templateId: 'TEMPLATE_ID_RESULT',
  data: {
    thing1: { value: '您的预约已被接受' },
    time2: { value: booking.date + ' ' + booking.time },
    phrase3: { value: '已接受' }
  },
  page: 'pages/student/my-bookings/index'
})
```

> ⚠️ `thing1`、`time2`、`phrase3` 这些字段名取决于你在微信公众平台选用的模板，需要对照实际模板中的字段名称来填写。

## 11. 提交审核与上线

### 11.1 提交审核

1. 确认所有功能测试通过后，在开发者工具中点击「上传」
   - 版本号：`1.0.0`
   - 备注：`平安驾校预约小程序首次发布`

2. 打开微信公众平台 →「版本管理」→「提交审核」

3. 填写审核信息：
   - 功能描述：`驾校预约小程序，学员可预约参观驾校和预约上课时间，教练可查看和管理预约`
   - 测试账号：提供教练的微信号（审核人员需要测试管理端）

4. 提交等待审核（通常 1-7 个工作日）

### 11.2 发布上线

1. 审核通过后，在公众平台「版本管理」中点击「发布」
2. 发布后学员可通过以下方式找到小程序：
   - 微信顶部搜索小程序名称
   - 教练分享小程序码给学员
   - 打印小程序码贴在驾校

## 13. 常见问题

### ❓ 小程序打开后一直转圈/白屏

**原因：** 云函数未上传或 `env.js` 配置错误
**解决：**
1. 检查 `env.js` 中的 `CLOUD_ENV` 是否正确
2. 确认所有 11 个云函数都已上传到云端
3. 在开发者工具 Console 面板看报错信息

### ❓ 提示"获取身份失败"

**原因：** login 云函数未正确上传
**解决：** 重新右键上传 login，选择「云端安装依赖」

### ❓ 教练打开后是学员界面（不是管理界面）

**原因：** `admins` 集合中没找到对应记录
**解决：** 确认 `admins` 集合中教练记录的 `openid` 与教练微信的实际 OpenID 完全一致

### ❓ 学员提交预约后没收到通知

**原因：** 订阅消息模板未配置
**解决：** 完成第 10 步配置模板 ID，且学员需要主动授权一次

### ❓ 数据库 permission denied

**原因：** 云函数权限不足
**解决：** 云开发控制台 → 设置 → 权限 → 设为「所有用户可读，仅管理员可写」

### ❓ 管理首页显示"0"条数据

**原因：** 管理员身份未识别或确实没有数据
**解决：** 先检查第 7.1 步的 OpenID 是否配置正确
