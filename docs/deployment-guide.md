## 1. 准备工作

### 1.1 安装微信开发者工具

去官网下载并安装 **微信开发者工具**（稳定版）：
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 1.2 获取小程序 AppID

1. 打开 https://mp.weixin.qq.com/ 登录你的微信公众平台
2. 如果没有小程序，点击「立即注册」→ 选择「小程序」→ 用教练的微信号注册
3. 注册完成后，在「开发」→「开发管理」→「开发设置」中复制 **AppID（小程序ID）**

> 💡 注册小程序需要提供邮箱（未注册过微信公众平台的），以及教练的身份证信息

### 1.3 获取教练的微信 OpenID

1. 在小程序公众平台「开发」→「开发管理」→「开发设置」中查看
2. 或者等后面跑通小程序后，在云开发控制台的数据库 `students` 集合中查看第一条记录的 `openid` 字段——那个就是教练的 OpenID（教练先登录一次小程序就会自动记录）

## 2. 创建微信云开发环境

1. 用微信开发者工具打开本项目
   - 打开工具 → 项目 → 导入项目
   - 目录选择：`d:/Code/wechat-driving`
   - AppID：填入上面获取的 AppID
   - 点击导入

2. 开通云开发
   - 点击顶部工具栏的「云开发」按钮（云朵图标 ☁️）
   - 点击「开通」
   - 环境名称：填 `driving-school-prod`（或你喜欢的名字）
   - 点击确定，等待创建完成（约 1-2 分钟）

3. 记录环境 ID
   - 创建完成后，在云开发控制台顶部能看到 `环境 ID：driving-school-prod-xxxxx`（一串字符）
   - 复制这个环境 ID，后面要用

---

## 3. 创建数据库集合

1. 在云开发控制台中，点击「数据库」标签页
2. 点击「创建集合」，依次创建以下 **4 个集合**：

| 集合名 | 说明 |
|--------|------|
| `students` | 学员信息 |
| `admins` | 管理员（教练） |
| `visits` | 参观咨询记录 |
| `bookings` | 上课预约记录 |

3. 为 `students` 集合的 `openid` 字段创建索引
   - 点击 `students` 集合 →「索引管理」→「添加索引」
   - 字段名：`openid`，方向：**唯一**
   - 点击确定

4. 为 `bookings` 集合创建索引
   - 点击 `bookings` 集合 →「索引管理」
   - 添加以下索引：

| 字段名 | 方向 |
|--------|------|
| `openid` | 升序 |
| `status` | 升序 |
| `date` | 升序 |

## 4. 插入管理员数据

1. 在云开发控制台 → 数据库 → 点击 `admins` 集合
2. 点击「添加记录」→ 选择「插入一条记录」
3. 把下面的 JSON 粘贴进去，**修改其中的值**：

```json
{
  "openid": "",
  "name": "张教练",
  "phone": "13800138000",
  "schoolName": "平安驾校",
  "address": "广东省汕头市龙湖区xx路xx号",
  "intro": "专业驾驶教练，多年教学经验，耐心负责，C1/C2均可教学。",
  "wechatQR": ""
}
```

> ⚠️ `openid` 先留空，等教练第一次登录小程序后，在云开发控制台的 `students` 集合中找到教练的记录，复制那个 `openid` 值，再回来修改 `admins` 记录的 `openid`
>
> `wechatQR` 先留空，等第 7 步上传二维码后再填写

4. 点击「确定」保存

## 5. 配置项目参数

### 5.1 配置环境 ID 和 OpenID

打开 `miniprogram/env.js`，修改：

```javascript
const CLOUD_ENV = '你的云环境ID'   // 替换为第2步中获取的环境ID
const ADMIN_OPENID = ''            // 等第4步拿到教练的OpenID后填入
```

### 5.2 配置 AppID

打开 `project.config.json`，修改第 12 行：

```json
"appid": "wx你的AppID"  // 替换为第1.2步获取的AppID
```

## 6. 上传云函数

每个云函数都需要上传到云端才能运行。有 11 个云函数需要上传：

```
cloudfunctions/
├── login/
├── getSchoolInfo/
├── submitVisit/
├── getVisits/
├── markContacted/
├── submitBooking/
├── getMyBookings/
├── getAllBookings/
├── handleBooking/
├── getSchedule/
└── sendNotify/
```

### 方法一：逐个上传（推荐第一次用）

在微信开发者工具中：
1. 展开左侧的 `cloudfunctions/` 目录
2. 右键点击 `login` 文件夹 →「上传并部署：云端安装依赖」
3. 等待上传完成（第一次较慢，约 30 秒 - 1 分钟）
4. 重复以上操作，依次上传 **全部 11 个云函数**

### 方法二：批量上传脚本

在项目根目录打开终端（微信开发者工具 → 顶部菜单「工具」→「打开命令行」），运行：

```bash
# Windows (在项目根目录执行)
for %d in (login getSchoolInfo submitVisit getVisits markContacted submitBooking getMyBookings getAllBookings handleBooking getSchedule sendNotify) do (cd cloudfunctions\%d && npm install && cd ../..)
```

然后在开发者工具中逐一右键上传。

## 7. 上传微信二维码到云存储

### 7.1 准备二维码

1. 让教练打开微信 → 我 → 点头像 → 点「二维码名片」
2. 截图保存到电脑（或者用另一台手机拍）
3. 图片命名为 `wechat-qr.jpg`

### 7.2 上传到云存储

1. 在云开发控制台点击「存储」标签页
2. 点击「上传文件」，选择 `wechat-qr.jpg`
3. 上传成功后，点击文件右侧的「复制文件 ID」
4. 回到数据库 → `admins` 集合 → 打开管理员那条记录
5. 把 `wechatQR` 字段的值改为刚才复制的文件 ID（格式如：`cloud://driving-school-prod-xxxx.xxx/wechat-qr.jpg`）
6. 点击「确定」保存

## 8. 配置订阅消息模板

### 8.1 申请模板

1. 打开微信公众平台（https://mp.weixin.qq.com/）
2. 登录小程序账号
3. 左侧菜单：「功能」→「订阅消息」
4. 点击「公共模板库」
5. 搜索以下模板并选用：

| 用途 | 推荐搜索关键词 | 模板内容建议 |
|------|---------------|-------------|
| 新预约通知 → 教练 | "预约提醒"、"新订单通知" | 学员姓名、预约日期、预约时间、提交时间 |
| 预约结果 → 学员 | "状态通知"、"审核结果通知" | 预约日期、预约时间、审核状态、备注 |

6. 选用模板后，记录下每个模板的 **模板 ID**（一串以 `TEMPLATE_ID_` 开头的字符串）

### 8.2 在代码中配置模板 ID

打开以下文件，在 `wx.requestSubscribeMessage` 调用的 `tmplIds` 数组中填入模板 ID：

**文件 1：** `miniprogram/pages/student/visit/index.js`（约第 26 行）
```javascript
wx.requestSubscribeMessage({
  tmplIds: ['TEMPLATE_ID_VISIT_NOTIFY'],  // ← 替换为实际模板ID
  complete: () => { ... }
})
```

**文件 2：** `miniprogram/pages/student/booking/index.js`（约第 60 行）
```javascript
wx.requestSubscribeMessage({
  tmplIds: ['TEMPLATE_ID_BOOKING_NOTIFY'],  // ← 替换为实际模板ID
  complete: () => { ... }
})
```

**文件 3：** `miniprogram/pages/admin/bookings/index.js`（约第 25 行起）
找到 `acceptBooking` 和 `rejectBooking` 中的 `// TODO` 注释，替换为实际的 `cloud.sendNotify()` 调用：

```javascript
// 接受后通知学员示例：
const booking = this.data.list.find(b => b._id === e.currentTarget.dataset.id)
cloud.sendNotify({
  openid: booking.openid,
  templateId: 'TEMPLATE_ID_RESULT',  // 替换为实际模板ID
  data: {
    thing1: { value: '您的预约已被接受' },
    time2: { value: booking.date + ' ' + booking.time },
    phrase3: { value: '已接受' }
  },
  page: 'pages/student/my-bookings/index'
})
```

> ⚠️ 具体 data 字段名（如 `thing1`、`time2`）取决于你在微信公众平台选择的模板，需要对照实际模板中的字段名称来填写。

## 9. 真机调试

### 9.1 预览

1. 点击微信开发者工具顶部的「预览」按钮
2. 用微信扫码打开小程序
3. 测试以下完整流程：

**学员流程：**
- [ ] 打开小程序 → 自动跳转学员首页
- [ ] 首页显示驾校信息（名称/地址/教练/简介）
- [ ] 点击「预约参观」→ 填写手机号 → 提交
- [ ] 点击「预约学车」→ 选择日期时间科目 → 添加多个日期 → 提交
- [ ] 点击底部「我的」→ 看到刚才提交的预约记录
- [ ] 查看预约详情
- [ ] 点击底部「联系」→ 显示二维码/复制微信号/拨打电话/客服按钮

**管理员流程：**
- [ ] 用教练的微信打开小程序 → 自动跳转管理首页
- [ ] 首页显示统计数据（待处理数/咨询数/已确认数）
- [ ] 点击「预约管理」→ 看到学员提交的预约
- [ ] 点击「接受」→ 预约状态变为已接受
- [ ] 点击「拒绝」→ 弹窗输入原因 → 状态变为已拒绝
- [ ] 点击「咨询学员」→ 看到参观咨询列表
- [ ] 点击「课程表」→ 按周查看已确认的课程

### 9.2 获取教练的 OpenID

1. 用教练的微信扫码预览小程序
2. 在云开发控制台 → 数据库 → `students` 集合
3. 应该看到一条新增的记录，其中的 `openid` 字段就是教练的 OpenID
4. 把这个值填入：
   - `miniprogram/env.js` 的 `ADMIN_OPENID`
   - `admins` 集合管理记录的 `openid` 字段

## 10. 提交审核与上线

### 10.1 提交审核

1. 在微信开发者工具中点击「上传」
   - 版本号：`1.0.0`
   - 备注：`平安驾校预约小程序首次发布`
2. 打开微信公众平台 →「版本管理」→「提交审核」
3. 填写审核信息：
   - 功能描述：`驾校预约小程序，学员可预约参观驾校和预约上课时间，教练可查看和管理预约`
   - 测试账号：提供教练的微信号
4. 提交等待审核（通常 1-7 个工作日）

### 10.2 发布上线

1. 审核通过后，在公众平台「版本管理」中点击「发布」
2. 发布后即可通过以下方式使用：
   - 微信搜索小程序名称
   - 扫码小程序码
   - 教练在微信中分享给学员

## 11. 后续维护

### 11.1 修改驾校信息

如果驾校地址、电话等信息变了：

1. 打开云开发控制台 → 数据库 → `admins` 集合
2. 找到管理员那条记录
3. 直接修改对应字段的值即可（小程序会实时读取最新数据）

### 11.2 更换微信二维码

1. 云开发控制台 → 存储 → 上传新图片
2. 复制新图片的 fileID
3. 数据库 → `admins` → 替换 `wechatQR` 字段值

### 11.3 查看预约数据

- 所有预约数据在云开发控制台 → 数据库 → `bookings` 集合中
- 可以导出为 JSON 做备份或分析

### 11.4 更新云函数

如果修改了云函数代码：
1. 右键云函数文件夹 →「上传并部署：云端安装依赖」
2. 重新提交小程序审核（如果涉及页面改动）

## 12. 常见问题

### ❓ 小程序打开后一直转圈/白屏

**原因：** 云函数未上传或配置错误
**解决：** 
1. 检查 `env.js` 中的 `CLOUD_ENV` 是否正确
2. 确认所有云函数都已上传
3. 在开发者工具 Console 面板看是否有报错信息

### ❓ 提示"获取身份失败"

**原因：** 云函数 login 未正确配置
**解决：** 检查云函数 login 是否已上传，是否为「云端安装依赖」模式

### ❓ 学员提交预约后教练没收到通知

**原因：** 订阅消息模板未配置
**解决：** 需要先完成第 8 步（配置订阅消息模板），且学员需要主动授权一次

### ❓ "数据库 permission denied"

**原因：** 云函数未使用正确的权限
**解决：** 在云开发控制台 → 设置 → 权限设置中，将数据库读写权限设为「所有用户可读，仅管理员可写」或按云函数方式管理权限

### ❓ 管理首页显示"0"条数据

**原因：** 管理员身份未识别
**解决：** 确认 `admins` 集合中的 `openid` 与教练微信的实际 OpenID 一致
