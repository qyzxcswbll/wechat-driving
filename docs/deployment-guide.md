## 1. 准备工作

### 1.1 安装微信开发者工具

下载并安装 **微信开发者工具**（稳定版）：
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

> 你只需要它的上传和预览功能，日常改代码还是在 VS Code 中进行。

### 1.2 注册小程序并获取 AppID

1. 打开 https://mp.weixin.qq.com/
2. 点击「立即注册」→ 选择「小程序」
   - 用**你本人的邮箱**注册（未注册过微信公众平台的）
   - 主体类型选「个人」
   - 用你本人的身份证信息完成实名
3. 注册完成后，在「开发」→「开发管理」→「开发设置」中复制 **AppID（小程序ID）**

> 小程序是**以你的名义注册**用于发布和运营，教练不需要注册账号。

## 2. 创建微信云开发环境

1. 用微信开发者工具打开本项目
   - 打开工具 → 项目 → 导入项目
   - 目录选择：`d:/Code/wechat-driving`
   - AppID：填入上一步获取的 AppID
   - 点击导入

2. 开通云开发
   - 点击顶部工具栏的「云开发」按钮（云朵图标 ☁️）
   - 点击「开通」→ 选 **免费版**
   - 环境名称：填 `driving-school-prod`
   - 点击确定，等待创建完成（约 1-2 分钟）

3. 记录环境 ID
   - 创建完成后，云开发控制台顶部显示 `环境 ID：driving-school-prod-xxxxx`
   - **复制这个环境 ID**，下一步要用

---

## 3. 创建数据库集合

1. 在云开发控制台中，点击「数据库」标签页
2. 点击「创建集合」，依次创建以下 **4 个集合**（权限都选「仅创建者可读写」）：

| 集合名 | 说明 |
|--------|------|
| `students` | 学员信息 |
| `admins` | 管理员（教练） |
| `visits` | 参观咨询记录 |
| `bookings` | 上课预约记录 |

3. 为 `students` 集合的 `openid` 字段创建**唯一索引**
4. 为 `bookings` 集合创建普通索引（`openid`、`status`、`date`，升序）
5. 为 `visits` 集合创建 `createdAt` 降序索引

## 4. 配置项目参数

### 4.1 配置云环境 ID

打开 `miniprogram/env.js`：

```javascript
const CLOUD_ENV = 'driving-school-prod-xxxxx'   // ← 替换为第2步获取的环境ID
const ADMIN_OPENID = ''                          // 留空即可
```

### 4.2 配置 AppID

打开 `project.config.json`：

```json
"appid": "wx你的AppID"  // ← 替换为第1.2步获取的AppID
```

## 5. 上传云函数

共 **18 个云函数**需要上传到云端。在开发者工具中展开 `cloudfunctions/`，**逐一右键 → 「上传并部署：云端安装依赖」**：

```
login / getSchoolInfo / submitVisit / getVisits / getMyVisits
markContacted / submitBooking / getMyBookings / getAllBookings
handleBooking / getSchedule / cancelBooking / sendNotify
setupVerify / setupGetAllStudents / setupGetAdmins
setupSetAdmin / setupUpdateSchool
```

> 每个云函数第一次上传约 30 秒，全部传完约 10 分钟。

4. 在「学员管理」中找到教练的名字 → 点 **「设为教练」**

## 10. 提交审核与上线

### 10.1 提交审核

1. 打开微信公众平台（https://mp.weixin.qq.com/）
2. 登录小程序账号
3. 左侧「版本管理」→ 找到刚上传的版本 → **「提交审核」**

填写：
- 功能描述：`学员预约学车/参观小程序，教练可管理预约和课程表`
- 测试账号：提供教练的微信号

4. 提交等待审核（通常 1-7 个工作日）

### 10.2 开通客服消息（审核期间可以做）

审核期间，去公众平台 → 「功能」→「客服消息」→ 添加教练的微信号为客服人员。
这样用户点「联系客服」发的消息，教练能在手机上收到和回复。

### 10.3 发布上线

1. 审核通过后，在「版本管理」中点击「发布」
2. 发布后学员可通过以下方式找到小程序：
   - 微信顶部搜索小程序名称
   - 教练分享小程序码给学员
   - 打印小程序码贴在驾校

## 12. 常见问题

### ❓ 小程序打开后一直转圈/白屏

**原因：** 云函数未上传或 `env.js` 配置错误
**解决：**
1. 检查 `env.js` 中的 `CLOUD_ENV` 是否正确
2. 确认所有 18 个云函数都已上传到云端
3. 在开发者工具 Console 面板看报错信息

### ❓ 教练打开后是学员界面

**原因：** `admins` 集合中没有对应记录
**解决：** 用 ⚙️ 设置页「学员管理」中找到教练 → 点「设为教练」

### ❓ 通知发不出去

**原因：** 接收方未授权或模板 ID 不对
**解决：** 
- 教练在管理首页底部点「如未收到通知，点此重新授权」
- 学员提交预约时会自动弹授权窗

### ❓ 联系客服按钮点了没反应

**原因：** 客服功能未开通
**解决：** 公众平台 → 功能 → 客服消息 → 添加客服人员

### ❓ 数据库 permission denied

**原因：** 云函数权限不足
**解决：** 云开发控制台 → 设置 → 权限 → 设为「所有用户可读，仅管理员可写」
